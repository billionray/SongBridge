# SongBridge 浏览器助手

统一 ZIP 支持 Windows（Edge）、macOS（Chrome 或 Edge）和 Linux 图形桌面（Chrome、Chromium 或 Edge）。使用 Node.js 22 或更新版本。

1. 解压到一个新文件夹，Windows 在 PowerShell 中运行 .\start.ps1，macOS 双击「start.command」，Linux 运行 sh start.sh，也可以在目录内执行 node start.mjs。首次运行会联网安装 Playwright Core（使用本机已有浏览器）。
2. 在 SongBridge 网页选择「浏览器导入」，输入窗口显示的本次连接码。
3. 打开 Apple Music 登录，在独立浏览器窗口内登录国区账户。订阅需有效。
4. 返回 SongBridge 读取或载入歌单，点击开始匹配，核对歌曲版本并勾选。
5. 点击确认导入。目标名称与导出名称一致，同名歌单存在则继续添加，不存在则新建。每次导入先滚动读取目标歌单，已有歌曲及本次重复项自动跳过；多个同名歌单时停止，请先区分名称。

只通过网页 DOM 和点击操作，不读取登录令牌，不要求开发者账号。账号会话仅保留在本机 .state/profile 中；不要分享 .state 文件夹。助手仅监听 127.0.0.1:17321，连接码每次启动更新。网页和助手需在同一台电脑，允许浏览器的本地网络连接提示。

匹配可暂停后继续。导入可暂停后继续，继续前重新读取目标歌单去重。单首失败会记入报告，任务继续。待核对的歌曲默认不选中，可在批次结束后单独勾选重试。关闭窗口会断开助手；关闭网页不会停止正在运行的任务，请先点暂停。

歌单没有曲数文案时仍可核对。分页加载超时后，助手用已读歌曲去重并继续导入，未读到的部分可能重复添加。批次结束后重新打开目标歌单，只有读到对应 Apple Music 歌曲 ID 才确认成功。升级后，旧版未核实的成功记录会恢复为已匹配，可以先点「仅核对目标歌单」，再导入缺少的歌曲。浏览器模式仍为测试版，首次请用少量歌曲核验。

自动读取 HTTPS_PROXY / HTTP_PROXY / ALL_PROXY 环境变量，其次读取 Windows 或 macOS 系统 HTTP(S) 代理；不扫描端口、不写死端口。依赖安装与独立 Edge 使用检测到的代理，本地助手连接直连。若只有 PAC 自动配置，Edge 沿用系统设置；npm 不解析 PAC，需提供 HTTP(S) 代理环境变量后安装依赖。普通浏览器访问 SongBridge 网站沿用浏览器自身代理设置。
点击“开始匹配”，助手先搜索来源歌名和完整艺人署名，未选中版本时再只搜原歌名。两次查询都核对艺人和录音版本，手动修正读音也只用于比对。歌名与艺人可分别双向比较日文和罗马音。候选显示角色、声优或录音差异。歌名和艺人对应时显示浅绿色，转写接近或发行版本并列时显示黄色，合作署名有差异时显示橙色。录音版本冲突显示红色，保留手选。独立英文译名无法核实时，可从原始查询结果中选择。每轮显示自动选中、需手选、未找到的数量。单曲重搜可手动修正读音，已选定的 Apple Music 版本会按对应搜索词重新定位。覆盖更新时保留 .state，重新启动助手 安装词典。目标歌单分页读取超时后可继续读取，取消待核对歌曲再导入会将它搁置。


核对视图可切换为「只看需要核对的」，显示黄色和橙色。取消勾选要重新判断的歌曲后点「继续匹配」；助手会保存勾选状态。刷新网页后，输入连接码可恢复本地任务。

Linux 依次检查环境代理和 GNOME 手动代理；其他桌面使用浏览器系统设置或环境变量。可用 SONGBRIDGE_BROWSER 指定浏览器绝对路径。

搜索页超时会短暂等待并重试；只读菜单准备阶段也可重试。助手每处理 25 首会检查已提交的目录 ID，批末留出同步时间再复核。未选中且含日文的歌曲可以按国区候选已有的目录 ID 请求日区标题和艺人。
